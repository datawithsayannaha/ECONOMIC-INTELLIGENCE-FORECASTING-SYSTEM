## 📈 Power BI Dashboard

The repository includes a comprehensive Power BI dashboard (`.pbix`) developed from the final analytical datasets generated in Python. 
The dashboard transforms complex economic data, statistical findings, machine learning outputs, and forecasting results into interactive business intelligence reports.
